# Problem Discovery 范围

> 状态：Problem Discovery。当前范围约束调查活动，不定义最终产品或生产架构。

## 调查目标

识别并验证 VLA 推理与机器人部署中一个真实存在、可重复、尚未被现有方案充分解决且值得投入的问题。

调查必须回答：

1. 谁遇到了问题；
2. 他正在完成什么工作；
3. 预期和实际行为是什么；
4. 问题造成什么影响；
5. 当前版本是否仍可复现；
6. 根因是什么；
7. 现有修复、PR 或替代方案为什么不足；
8. 最小修复或不可修复结论是什么；
9. 以什么证据判断影响得到解决。

## 候选调查边界

真实项目 Issue 是问题线索来源，不是预先确定的项目场景或已验证事实。问题池顺序、当前关注方向和数量限制由[候选 Issue 筛选表](../research/issue-candidates.md#问题池顺序)维护。

对被选 Issue 只执行问题原生路径所需的复现、根因分析、最小修复或不可修复结论，以及与问题声明匹配的影响验证。模型、checkpoint、Processor、Runtime、实现语言、协议、仿真、控制端和硬件仅在相关时进入调查。

预期行为、官方参考或已有测试可以作为正确性基线。`vla.cpp`、`Embodied.cpp` 和 GR00T 官方部署路径只在相关问题下作为事实来源、对照、诊断或上游贡献工具，不是必经路径或生产候选清单。

## 本阶段必须产出

所有退出结果都必须记录并保存：

- 不超过 10 个候选 Issue 的来源和筛选依据；
- 进入 shortlist 的 Issue、受影响版本、环境和工作流；
- 问题原生路径的复现命令与结果，或无法形成可执行复现的证据；
- 官方声明、代码检查、受控环境复现和测量的证据等级；
- 首个稳定问题的证据，或“未发现有价值缺口”的结论；
- `Continue`、`Contribute upstream` 或 `Stop/Pivot` 决策。

候选进入复现准备后，凡是会影响复现结果的模型、checkpoint、Processor、Runtime、协议、控制端和硬件版本，都必须随环境一并固定。稳定问题成立且对应字段适用时，最终证据包还必须记录：

- 与问题相关的资产版本及其适用范围；
- 仅覆盖根因假设和替代方案反证所需维度的对照；
- 根因及其代码、配置、数据、资源或协议证据；
- 与根因匹配的最小修复，或无法安全修复的明确结论；
- 能在修复前失败、修复后通过的回归验证；
- 与问题声明匹配的数值、资源、动作、仿真、控制端或异常影响验证。

这些是调查产物，不是生产系统交付物。

## 当前不实施

- 冻结最终项目目标、生产模型、Runtime、后端、硬件或控制路径；
- 新建与被选 Issue 无关的完整推理 Runtime；
- 实施未经问题证据触发的安全架构或正式机器人控制链路；
- 扩展未经问题证据触发的生产级测试、制品和发布系统；
- 多模型在线切换、通用插件框架或云端多租户 Serving；
- VLA 预训练、训练算法、视觉算法或世界模型研究；
- 真实机器人高风险动作或功能安全能力声明。

发现问题所需的最小测试夹具、一次性脚本或隔离环境可以在后续获得授权后实施，但不得演变为未经立项的生产架构。

## 资源与硬件约束

- Problem Discovery 默认使用当前本地设备开发和执行能够完成的最小复现；
- 后续操作系统以原生 Ubuntu 桌面版为候选，但具体版本须结合 GPU 驱动、CUDA 和被选 Issue 路径及相关实现的兼容性验证后确定；
- 允许把借用设备、Jetson 和有费用上限的临时云 GPU 作为候选验证资源，但当前不冻结平台或采购方案；
- 稳定问题成立前，只允许使用已有设备、借用设备或有费用上限的临时资源验证资源假设，不进行长期硬件采购；
- 只有稳定问题成立，且复现暴露可归因的算力、显存、指令集、驱动或平台兼容性阻塞后，才进入长期硬件采购决策；
- 采购或升级前必须比较缩小模型/量化、调整复现路径、临时云 GPU 和现有硬件升级等替代方案；
- 设备价格、岗位展示价值或“更像生产环境”不能单独作为采购依据。

当前设备事实、平台候选和资源升级门禁由[部署平台候选调研](../research/deployment-platforms.md)维护，避免在范围文档中重复易变化的规格。

`Continue` 只表示可以基于已验证问题另行定义下一步，不自动恢复任何旧架构、范围或阶段计划。

## 数据与证据边界

证据等级、失败分类和替代方案反证统一由 [Problem Discovery 计划](../plans/phase-0.md#证据规则)定义。仿真、公开数据和真机证据必须分别记录来源、许可证和适用范围；没有满足计划中的证据要求时，结论保持为 `Unknown` 或 `Insufficient evidence`。
